# Realtime Identity Event Pipeline

High-throughput real-time identity graph resolution, touchpoint event streaming, and attribution pipeline built with TypeScript and Node.js.

## Capabilities
- **Deterministic Identity Graph**: Graph-based identity resolution joining anonymous cookies, hashed emails, and authenticated user IDs into unified personas.
- **Real-Time Touchpoint Ingestion**: Multichannel event validation, timestamp ordering, and session stitching.
- **Attribution & Aggregation**: Real-time attribution modeling across multichannel touchpoints.
